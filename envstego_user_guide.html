EnvStego step-by-step user guide

When you first open the app
1
Wait for signals to load
The app scans your machine automatically. You'll see "Collecting…" in the top right. This takes 5–15 seconds. Once done, the Signals tab fills up with rows — some green, some grey.
Green = Available — the app could read this signal from your machine.
Grey N/A = not accessible (e.g. no battery on a desktop, no Wi-Fi adapter).
2
Pick your signals (Signals tab)
Tick the signals you want to form your encryption key. The more you select, the harder the key is to recreate elsewhere. Available signals are pre-ticked — you can untick ones you don't want.
Rule of thumb: pick at least 3 signals. Machine GUID + Volume Serial + one network signal is a solid starting combination.
Stability 8–10 = very reliable Stability 5–7 = can change
3
Test your key
Click Test Key at the bottom of the Signals tab. A fingerprint appears (e.g. D993-8D9E-DA56-3DEA). Click it again — if the fingerprint is identical, your environment is stable and safe to use for encryption.
Encrypting a file
4
Go to the Encrypt tab
You need three things: a payload file (any file you want to hide), a carrier PNG image (the image the data gets hidden inside), and an output path (where to save the result).
Payload: any file — .txt, .pdf, .docx, etc.
Carrier: must be a PNG. Bigger image = more capacity. A 1920×1080 PNG holds ~759 KB.
5
Check the capacity bar
After selecting your carrier and payload, a bar shows how much of the image's capacity the payload uses. If it turns red, your image is too small — use a larger PNG.
Blue bar = fits fine Red bar = image too small
6
Click "Encrypt & Embed"
The app encrypts your file with AES-256-GCM using the key derived from your selected signals, then hides the encrypted data in the PNG's pixel values (LSB steganography). The output image looks identical to the original.
Note the key fingerprint shown after success — this confirms which environment was used. You'll need the same signals active to decrypt.
Decrypting a file
7
Make sure the same signals are selected
Go back to the Signals tab. The same signals that were ticked during encryption must be ticked now. If you're on a different machine or network, decryption will fail — that's the forensic defence working.
8
Go to the Decrypt tab
Select the stego PNG (the output image from step 6) and choose where to save the recovered file. Click Decrypt & Extract.
Correct environment → file recovered Wrong environment → authentication fails
Bonus
9
Inspector tab — see raw signal values
Shows you exactly what value was read for each signal. Useful for your report's evaluation section and for debugging if a signal shows N/A unexpectedly.
10
Refresh Signals button
Top right corner. Re-scans your machine — useful if you connected to a different Wi-Fi network and want to use the new BSSID as part of your key.
